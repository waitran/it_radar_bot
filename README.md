# it_radar_bot

## Описание сервиса

Сервис (`it-radar-bot`) — Telegram-бот, который автоматически отслеживает актуальные возможности для студентов и начинающих IT-специалистов в заданных источниках и присылает владельцу только новые подходящие публикации: стажировки и программы для начинающих, IT-мероприятия (митапы, конференции, лекции), хакатоны/соревнования/олимпиады/конкурсы, карьерные встречи. Обычные новости компаний и реклама продуктов отсекаются настраиваемыми правилами.

### Источники

**Telegram-каналы** читаются только через открытые веб-страницы `https://t.me/s/<username>` (без Telethon/Pyrogram/MTProto и без пользовательского аккаунта):
- t.me/rostelecom_tech
- t.me/rostelecom_molodezh
- t.me/CTDLru
- t.me/mgtsstudents
- t.me/brainzbycroc
- t.me/k2cybersec_team
- t.me/rvision_team

**Сайты компаний** (RSS/API отсутствуют — проверено; для каждого сайта написан отдельный сборщик под его структуру):
- https://careers.cybersecurity.k2.tech/vacancy — публичный JSON-эндпоинт каталога Tilda (`app/collectors/k2.py`)
- https://careers.croc.ru/vacancies/?_sft_expirience=0-1-год — HTML-карточки вакансий (`app/collectors/croc.py`)
- https://rtkit.ru/careers — SPA, данные извлекаются из статического JS-бандла (`app/collectors/rtkit.py`)

### Категории отбора (настраиваются в `config.yaml`)

| Категория | Что ищет |
|---|---|
| `internships` | стажировки, программы для начинающих, junior/entry-level, практики |
| `events` | митапы, конференции, лекции, воркшопы, вебинары, дни открытых дверей |
| `contests` | хакатоны, соревнования, олимпиады, конкурсы, CTF, кейс-чемпионаты |
| `career` | карьерные встречи, ярмарки вакансий, дни карьеры, подработка для студентов |

Ключевые слова каждой категории, стоп-слова (новости/реклама), минимальный балл совпадений и максимальный возраст публикации задаются в секции `rules` файла `config.yaml`.

### Уведомления

- Присылаются **только новые подходящие публикации**: категория, компания/канал, краткое содержание, ссылка на оригинал и ссылка на регистрацию/заявку (если найдена).
- Явно закрытые объявления и публикации с истёкшим сроком подачи не отправляются.
- Если статус регистрации неизвестен, бот не утверждает, что она открыта.
- При первом запуске архив не рассылается: текущие публикации запоминаются как исходная точка (baseline).

### Механика работы

- Опрос источников примерно раз в час (`POLL_INTERVAL_SECONDS`, по умолчанию 3600) с разумной частотой запросов и паузами между источниками.
- Ошибка одного источника логируется и не останавливает остальные.
- Все ID и ссылки публикаций сохраняются в SQLite (`data/bot.db`) — дубли исключены при повторных проверках и перезапусках; одно объявление, опубликованное и в канале, и на сайте, не придёт дважды (дедупликация по нормализованному названию).
- Если источник недоступен для автоматического чтения, бот прямо сообщает об этом в логах и не пытается обойти ограничения.

### Команды бота

- `/start` — включить рассылку (владелец получает сводку по подключённым источникам);
- `/stop` — остановить рассылку уведомлений.

Уведомления доставляются только владельцу, указанному в переменной окружения `OWNER_ID`.
